# CAN-Age
# CAN-Age: Color-Attention Based Deep Learning Architecture for Noninvasive Wildlife Age Estimation

This repository contains the official implementation code for the paper "CAN-Age: Color-Attention Based Deep Learning Architecture for Noninvasive Wildlife Age Estimation".

## Overview
Age estimation is essential for studying wildlife population structures. This repository provides the Jupyter Notebook (`CAN_Age_Estimation.ipynb`) used to visualize the CAN-Age results.


## Requirements
To run the notebook, please ensure you have the following dependencies installed:
* Python 3.8+
* PyTorch >= 1.9.0
* Pandas, NumPy
* Matplotlib, Seaborn (for generating density and ridgeline plots)
